# Erster PR – Übung

Dieses Repository ist ein Übungsprojekt, um den Ablauf eines Pull Requests auf GitHub kennenzulernen.

## Inhalt

Bisher gibt es hier nur diese README-Datei.

## So läuft ein Pull Request ab

1. Einen neuen Branch anlegen, zum Beispiel `git switch -c mein-branch`.
2. Dateien ändern und die Änderung committen.
3. Den Branch zu GitHub pushen: `git push -u origin mein-branch`.
4. Auf GitHub einen Pull Request gegen `main` öffnen, zum Beispiel mit `gh pr create`.
5. Die Änderungen prüfen und den Pull Request mergen.
